# 📊 Monitor de Surtos Epidemiológicos (Streamlit)

Este repositório contém ferramentas desenvolvidas em Python para a análise, filtragem e visualização de dados de surtos. O projeto oferece dois níveis de interação: um analisador simplificado para exportação de dados e um dashboard completo para geração de indicadores visuais.

## 🚀 Como Executar

### 1. Pré-requisitos
Certifique-se de ter o Python instalado. O projeto utiliza um `Makefile` para automatizar as tarefas comuns.

### 2. Configuração e Execução
No terminal, utilize os seguintes comandos:

```bash
# Instalar as dependências necessárias
make install

# Executar a versão de análise rápida (Tabelas e Filtros)
make monitor

# Executar a versão Dashboard (Gráficos e Indicadores)
make dashboard
