# 📊 Monitor de Surtos 

Este repositório contém duas aplicações desenvolvidas em Python com **Streamlit** para a análise e visualização de dados de surtos. O objetivo é facilitar o tratamento de planilhas (CSV/XLSX), permitindo desde filtragens rápidas até a geração de dashboards completos.

## 🚀 Como Executar

### 1. Instalação
Certifique-se de ter o Python instalado. Utilize o `Makefile` incluído para configurar o ambiente rapidamente:

```bash
# Instala as dependências (Streamlit, Pandas, Plotly, Openpyxl)
make install
